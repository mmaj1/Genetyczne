# Wspólna mapa i oddzielny czas prezentacji wyścigu

Wyścig otrzymuje niezmienną kopię mapy, blokad, ziarna i parametrów. Korzysta z własnej kolonii, aby nie zmieniać feromonu ani postępu otwartej demonstracji mrówek. Alternatywa, czyli współdzielenie aktywnej kolonii i suwaków, pozwalałaby zmieniać problem w trakcie porównania i utrudniałaby interpretację wyników.

Jeden krok prezentacji przesuwa każdą niezakończoną metodę do kolejnego widocznego wyniku. Czas obliczeń sumujemy osobno wokół pracy algorytmu; nie wyciągamy go z długości animacji. Wynik dokładny dla małych map jest obliczany i mierzony osobno. Raport jest niezależną kopią obserwacji, więc późniejsza edycja mapy nie zmienia zapisanych wyników.
